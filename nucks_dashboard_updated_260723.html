데이터 업데이트 방법
대시보드를 최신 데이터로 유지하는 방법 안내

이 대시보드는 HTML 단일 파일로, 내부 JavaScript에 데이터가 포함됩니다. 아래 4가지 방법 중 하나를 선택하세요.

방법 0 — 대시보드에서 직접 업로드 (가장 빠름)

회계현황 엑셀 파일(.xlsb / .xlsx)을 아래에서 바로 업로드하면, 브라우저 안에서 즉시 모든 데이터·차트가 다시 계산됩니다. 파일은 이 브라우저 밖으로 전송되지 않으며, 이 브라우저의 로컬 저장소(localStorage)에만 저장됩니다.

업로드 데이터는 이 브라우저에만 저장됩니다(다른 PC·브라우저에서는 보이지 않음). "업데이트된 HTML로 저장"을 누르면 지금 반영된 데이터가 통째로 담긴 새 HTML 파일이 다운로드되며, 이 파일은 어디서 열어도 동일하게 보입니다 — 기존 파일을 이걸로 교체하거나 공유하면 됩니다.

시트명 거래내역이 포함된 엑셀 파일이어야 하며, 열 구성(연번·거래일자·출금·입금·구분·내용·잔액·메모·계정과목·프로젝트·프로젝트대분류·발주처)은 기존 양식과 동일해야 합니다.

방법 1 — Claude에 파일 업로드
1
엑셀 파일 업데이트
기존 넉스주식회사_회계현황xxxx.xlsb에 새 거래내역을 추가합니다.
2
Claude에 업로드 후 요청
업데이트된 파일을 첨부하고 아래와 같이 요청하면 새 HTML이 생성됩니다.
"업로드한 파일로 대시보드 HTML 업데이트해줘"
3
다운로드 및 교체
새로 받은 HTML 파일로 기존 파일을 교체하면 완료입니다.
방법 2 — HTML 직접 수정
1
텍스트 편집기로 열기
VS Code, 메모장 등으로 HTML 파일을 열고 Ctrl+F로 /* ── 실제 데이터 ──를 검색합니다.
