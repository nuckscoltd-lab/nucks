노션 CSV/엑셀 가져오기 (관리자)
파일에 담긴 모든 인원·기간의 데이터를 그대로 가져옵니다 (대상자/기간 필터 없음).
하루에 프로젝트가 여러 개(콤마로 구분) 기재된 경우, 총 근무시간을 프로젝트 개수만큼 균등 분할(1/n)해서 각각 별도 항목으로 저장합니다.
가져온 데이터 초기화 (재가져오기 전 정리용)
예전 버전으로 가져오기를 실행해서 프로젝트명이 콤마로 뒤섞여 들어간 데이터가 남아있을 때 쓰는 도구입니다. 위 가져오기 대상자(이연경·손영화·윤성원)의, 각자 가져오기 기준일 이후 근무일지를 통째로 지웁니다. 지운 뒤 위에서 원본 파일로 "파일 분석 → 가져오기 실행"을 다시 하면 깨끗하게(중복·뒤섞인 이름 없이) 다시 채워집니다. 이 기간에 직접 작성하신 근무일지가 있다면 그것도 함께 지워지니, 실행 전에 꼭 확인해 주세요.
2022~2023년 가져오기 데이터 정리 (프로젝트명→상세내용 이동, 1회성)
퇴사자 7명(김래정·박시연·신재훈·오지은·윤두현·조성채·한정식)의 2022~2023년 가져오기 데이터는 원본 파일의 "프로젝트" 칸에 실제로는 업무내용이 들어있었어요. 아래 버튼을 누르면 해당 기간 근무일지의 프로젝트명 칸 내용을 상세내용 칸으로 옮기고, 프로젝트명은 비웁니다(자동완성 목록에서도 자연히 사라집니다). 이미 정리된 항목은 다시 건드리지 않아서 여러 번 눌러도 안전해요. 프로젝트명 통일 작업은 아래 "프로젝트명 정리" 도구로 직접 진행해 주세요.
예전 구조 데이터 변환 (1회성)
단일 프로젝트 구조로 저장된 예전 근무일지를, 지금의 "프로젝트별 내역" 구조로 변환합니다. 이미 변환된 항목은 건드리지 않아서 여러 번 눌러도 안전해요.
프로젝트명 정리 (중복 통합)
가져오기 과정에서 같은 프로젝트가 표기 차이(띄어쓰기 등)로 여러 이름으로 흩어져 있을 수 있어요. 아래에서 같은 프로젝트를 가리키는 이름들을 체크하고, 통합할 이름을 입력한 뒤 실행하면 해당 근무일지들의 프로젝트명이 전부 하나로 바뀝니다.
