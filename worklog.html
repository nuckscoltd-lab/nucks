근무일지 엑셀로 내보내기 (관리자)
현재까지 작성된 전체 근무일지를 연도별로 시트를 나눠 엑셀로 내보냅니다. 프로젝트 칸에는 근무일지 화면 자동완성과 동일한 최신 프로젝트명 드롭다운이 걸려 있어서(프로젝트 결산·회계현황에 새로 추가된 이름도 다음 내보내기부터 자동 반영됨), 엑셀에서 기존 프로젝트명을 이 목록으로 바로 바꿔 넣을 수 있어요. 목록에 없는 새 프로젝트명은 드롭다운을 무시하고 셀에 직접 타이핑해서 자유롭게 입력하셔도 돼요(막지 않습니다) - 다만 이렇게 새로 타이핑한 이름이 드롭다운 목록 자체에 자동으로 추가되진 않아요(엑셀 자체 제약). 계속 쓸 이름이면 프로젝트 결산 페이지에 등록해두시면 다음 내보내기부터 정식으로 목록에 잡혀요. 주의: 엑셀에서 수정한다고 실제 근무일지가 바로 바뀌진 않아요. 프로젝트명 칸을 다 정리하신 뒤, 아래 "정리한 엑셀 다시 반영"에 그 파일을 그대로 올리면 실제 근무일지에 반영돼요(문서ID·항목번호 숨김열로 정확히 어느 근무일지인지 찾아서 프로젝트명만 바꿔치기하는 방식이라, 행을 추가/삭제하거나 숨김열을 건드리지 않고 프로젝트 칸만 고치시면 돼요).
위에서 내보낸 엑셀의 프로젝트명 칸을 정리하신 뒤, 그 파일을 여기 올리면 실제 근무일지의 프로젝트명이 엑셀에 적힌 값으로 바뀝니다(투입시간·업무유형·상세내용 등 다른 값은 건드리지 않아요).
노션 CSV/엑셀 가져오기 (관리자)
파일에 담긴 모든 인원·기간의 데이터를 그대로 가져옵니다 (대상자/기간 필터 없음).
하루에 프로젝트가 여러 개(콤마로 구분) 기재된 경우, 총 근무시간을 프로젝트 개수만큼 균등 분할(1/n)해서 각각 별도 항목으로 저장합니다.
가져온 데이터 초기화 (재가져오기 전 정리용)
예전 버전으로 가져오기를 실행해서 프로젝트명이 콤마로 뒤섞여 들어간 데이터가 남아있을 때 쓰는 도구입니다. 위 가져오기 대상자(이연경·손영화·윤성원)의, 각자 가져오기 기준일 이후 근무일지를 통째로 지웁니다. 지운 뒤 위에서 원본 파일로 "파일 분석 → 가져오기 실행"을 다시 하면 깨끗하게(중복·뒤섞인 이름 없이) 다시 채워집니다. 이 기간에 직접 작성하신 근무일지가 있다면 그것도 함께 지워지니, 실행 전에 꼭 확인해 주세요.
2022~2023년 가져오기 데이터 정리 (프로젝트명→상세내용 이동, 1회성)
퇴사자 7명(김래정·박시연·신재훈·오지은·윤두현·조성채·한정식)의 2022~2023년 가져오기 데이터는 원본 파일의 "프로젝트" 칸에 실제로는 업무내용이 들어있었어요. 아래 버튼을 누르면 해당 기간 근무일지의 프로젝트명 칸 내용을 상세내용 칸으로 옮기고, 프로젝트명은 비웁니다(자동완성 목록에서도 자연히 사라집니다). 이미 정리된 항목은 다시 건드리지 않아서 여러 번 눌러도 안전해요. 프로젝트명 통일 작업은 아래 "프로젝트명 정리" 도구로 직접 진행해 주세요.
예전 구조 데이터 변환 (1회성)
단일 프로젝트 구조로 저장된 예전 근무일지를, 지금의 "프로젝트별 내역" 구조로 변환합니다. 이미 변환된 항목은 건드리지 않아서 여러 번 눌러도 안전해요.
점심시간 제외 재계산 (기존 근무일지 일괄 적용, 1회성)
지금까지 근무일지의 총 근무시간은 "퇴근시간-출근시간"으로만 계산되어 점심시간이 그대로 포함돼 있었어요. 아래 버튼을 누르면 출근·퇴근시간이 있는 기존 근무일지 전체를 다시 확인해서, 아직 순수 시간차 그대로인 항목만 골라 "퇴근시간-출근시간-1시간(점심)"으로 총 근무시간을 다시 계산하고, 프로젝트별 투입시간도 같은 비율로 줄여서 합계가 새 총 근무시간과 맞도록 맞춥니다. 이미 이 계산으로 저장되어 있거나, 출근·퇴근시간이 없는 날(연차 등)은 건드리지 않아서 여러 번 눌러도 안전해요. 앞으로 새로 작성/가져오기하는 근무일지는 자동으로 점심시간이 제외된 값으로 저장됩니다.
프로젝트명 정리 (중복 통합)
아래 목록은 프로젝트명 자동완성 드롭다운에 실제로 뜨는 이름 전체예요(근무일지에 이미 쓰인 이름 + 회계현황 대시보드·프로젝트 결산 등에서 동기화된 이름 모두 포함) - 근무일지에 아직 안 쓰인 이름도 여기서 같이 정리할 수 있어요. 같은 프로젝트를 가리키는 이름들을 체크하고, 통합할 이름을 입력한 뒤 "통합" 버튼을 누르면 해당 근무일지들의 프로젝트명이 전부 하나로 바뀌고, 자동완성 드롭다운에서도 선택한 이름들 대신 통합한 이름 하나만 남아요(다른 페이지를 다시 열어도 다시 갈라지지 않아요). 근무일지에서 아예 안 쓰이고 목록에서만 지우고 싶으면 "삭제"를 쓰면 돼요.
