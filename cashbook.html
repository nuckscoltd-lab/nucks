이월잔액 설정
이 기준일 이후의 거래만 아래 목록에 반영/집계됩니다. 지금까지 쓰시던 엑셀의 "이월잔액" 행에 해당하는 값이에요.
거래 입력
계정과목·프로젝트·대분류·발주처는 비워둬도 저장됩니다. 프로젝트를 고르면 대분류·발주처가 자동으로 채워져요. 결제수단 "카드"는 목록에는 보이지만 통장 잔액·예상잔고에는 들어가지 않습니다(카드대금이 통장에서 나갈 때 이미 반영). 계정과목 "미지급금"(카드대금 결제)은 통장 잔액에는 반영되고 지출 집계에서만 제외됩니다. 급여는 "직원급여" / "임원급여"로 구분해 입력해주세요.
증빙: 이 거래에 세금계산서·현금영수증·일반계산서가 발행됐다면 종류를 골라주세요. 입금은 매출, 출금은 매입으로 보고 분기별 매입매출 화면에 월별로 자동 반영됩니다(집계 월은 "증빙 발행일" 기준, 비우면 거래일자 기준 / 증빙 금액을 비우면 거래금액 전체 / 공급가액·세액은 자동 계산). 통장 거래에만 적용돼요.
출금이 "확정" 상태로 저장되는 순간, 선택한 카드의 해당 월(거래일자 기준) 사용액에 이 금액이 자동으로 더해집니다. "예정" 상태로 저장하면 나중에 "확정 처리"를 누르는 시점에 반영돼요.
일반지출(기타) 카드 관리
공과금·보험·세금·이자상환·법인카드처럼 고정된 분류 탭이 따로 없는 일시적 납부건(예: 일회성 협회비, 벌과금 등)을 분기별 법인매입매출현황의 "일반지출(자동)"에 반영하고 싶을 때 여기서 카드를 만드세요. 카드를 추가하면 위 "거래 입력"의 연동 대상에서 바로 선택할 수 있고, 출금 거래를 그 카드에 연동해서 확정 저장하면 분기별 법인매입매출현황 페이지의 일반지출 자동집계에 그대로 반영됩니다.

고정 항목 (매월 반복되는 거래)
임차료·급여·통신비처럼 매달 같은 금액이 나가는 항목을 여기 한 번 등록해두면, 아래 "이 달에 일괄 추가" 버튼 한 번으로 예정 거래가 자동으로 채워집니다. 이미 추가된 달에는 같은 항목이 중복으로 들어가지 않아요.
여기 적어둔 계정과목·프로젝트는 "일괄 추가"로 만들어지는 예정 거래에 그대로 들어갑니다. 확정할 때 분류를 다시 입력하지 않아도 회계종합현황에 정확히 반영돼요. (급여는 "임원급여"/"직원급여"로, 카드대금은 계정과목 "미지급금"으로 적어주세요.)

세금계산서·현금영수증·일반계산서 발행 현황
거래에 입력한 증빙을 증빙 발행일 기준 월별로 모았습니다(입금=매출, 출금=매입, 예정 거래 포함). 이 숫자가 분기별 매입매출 화면에 자동으로 들어가며, 월말에 홈택스 확정 금액을 그쪽에서 입력하면 그 값이 우선합니다. "증빙 미입력"은 급여·카드대금·대출 등 증빙이 필요 없는 계정을 뺀 통장 확정 거래입니다 — 홈택스와 비교해 누락 점검에 쓰세요.
홈택스 증빙 자동 연결 (세금계산서 · 계산서 · 현금영수증)
홈택스에서 내려받은 전자세금계산서 목록(매출·매입), 전자계산서 목록, 현금영수증 매입내역 엑셀을 올려주세요(여러 개 동시 가능, 분기별 매입매출 화면의 "홈택스 가져오기"에 쓰시던 파일과 같은 형식). 시작일 이후의 증빙이 비어 있는 통장 거래를 금액·거래처·날짜로 맞춰 증빙 종류·발행일·공급가액·세액을 한 번에 달아줍니다. 이미 연결된 계산서는 다시 연결하지 않고, 미리보기에서 체크를 해제한 건은 적용되지 않아요. 급여·카드대금·대출 등 증빙이 필요 없는 계정은 대상에서 빠집니다.
엑셀 일괄 가져오기 / 내보내기
가져오기용 엑셀은 거래일자 / 구분 / 상태 / 금액 / 내용 / 비고 6개 컬럼 형식이어야 합니다. (선택 컬럼: 결제수단 / 계정과목 / 프로젝트 / 프로젝트대분류 / 발주처 / 증빙 / 증빙발행일 / 증빙금액) (구분: 입금 또는 출금 / 상태: 확정 또는 예정, 과거 데이터는 모두 "확정"으로 넣어주세요)
※ 엑셀로 가져온 항목과 "고정 항목 일괄 추가"로 생성된 항목은 연동 대상이 자동으로 지정되지 않습니다. 필요하면 아래 목록에서 "수정"을 눌러 연동 대상을 직접 지정해주세요.
회계 거래내역 엑셀 이전 (계정과목·프로젝트 포함)
기존 "회계현황" 엑셀의 거래내역 시트(거래일자·출금·입금·구분·내용·계정과목·프로젝트 …)를 읽어 이 페이지로 옮깁니다. 이미 등록된 거래는 그대로 두고, 겹치지 않는 거래만 추가합니다. 먼저 "분석하기"로 추가될 건수와 통장 잔액 영향을 확인한 뒤 확정 버튼을 눌러주세요. (구분: 지출→출금/통장, 카드매입→출금/카드, 수입→입금)
중복 의심 거래 정리 (합계로 나눠 입력된 중복)
같은 거래를 한쪽은 합계 1건, 다른 쪽은 여러 건(카드별 카드대금, 직원별 급여 등)으로 입력해 엑셀 이전 후 둘 다 남은 경우를 찾습니다. 같은 날짜(±3일)에서 여러 건의 합계가 1건과 정확히 같은 묶음만 보여주고, 미리보기에서 어느 쪽을 남길지 고를 수 있습니다(기본은 더 잘게 나뉜 쪽을 유지). 연동이 반영된 거래는 자동으로 지우지 않습니다. 지운 엑셀 거래는 기억해 두어서 엑셀을 다시 올려도 되살아나지 않습니다. 분류가 비어 있는 기존 지출도 함께 보여드립니다.
카드 이용내역 엑셀 업로드 (신한카드 · 현대카드)
카드사 사이트에서 내려받은 이용내역 엑셀 원본을 그대로 올려주세요(여러 파일 동시 선택 가능). 카드사는 열 이름으로 자동 구분합니다. 올린 거래는 결제수단 "카드"로 들어가 통장 잔액에는 영향이 없고, 이미 등록된 거래와 겹치면 건너뜁니다. 계정과목·프로젝트는 과거 같은 가맹점에서 쓰신 값으로 미리 채워 보여드립니다. 카드대금이 통장에서 빠져나간 건은 기존처럼 계정과목 "미지급금"으로 따로 입력하세요.
기본적으로 최근 3개월 내역만 표시됩니다. 이전 내역은 위 필터에서 "전체 월" 또는 원하는 월을 선택하면 볼 수 있어요. (잔액 계산에는 전체 데이터가 그대로 반영됩니다.)
